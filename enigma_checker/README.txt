ARK: Survival Ascended 生物所持チェックリスト

【使い方】
1. index.html と creatures.json を同じフォルダに置きます。
2. このフォルダでターミナル/コマンドプロンプトを開きます。
3. `python -m http.server 8000` を実行します。
4. ブラウザで http://localhost:8000 を開きます。

【言語切替】画面右上の「English / 日本語」ボタンで切り替えできます。選択した言語もブラウザに保存されます。
【保存】所持チェックは localStorage に保存されます。同じブラウザ・同じ端末で利用してください。
【生物データ】creatures.json の name は英語名、name_ja は日本語名です。
【移行】バックアップ/読み込みで所持状況を移行できます。
